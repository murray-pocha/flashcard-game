# HTMLfinal – Kids Word Game + Leaderboard

This project is a simple word game for young children with:
- A landing page that shows a flash-card style word game.
- A leaderboard page that tracks player scores.
- Login and signup pages.
- A PostgreSQL database to store words and scores.

## Project Structure

- `Frontend/`
  - `index.html` – landing page with the game
  - `leaderboard.html` – shows high scores
  - `login.html` – login form
  - `signup.html` – signup form
  - `css/` – stylesheets
  - `js/` – client-side JavaScript

- `Backend/`
  - `server.js` – Express server
  - `db/` – database connection and SQL files
